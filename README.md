# Word Count

A simple word counter built with vanilla JS. Type or paste text and it counts words, characters, sentences, and paragraphs. Has a dark/light mode toggle and saves your text to localStorage so it's still there when you refresh.

## Features
- Live word & character count
- Sentence and paragraph count
- Reading time estimate
- Dark/light mode toggle (remembers your choice)
- Auto-saves your text to localStorage


## How to run
Clone it, open `index.html`. Done.

## Built with
HTML, CSS, vanilla JS. No frameworks.

## What I learned
- localStorage for saving data
- Theme toggling with CSS classes
- Live DOM updates on input
